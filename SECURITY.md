# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of **distract.nvim** seriously. If you believe you have found a security vulnerability in the Rust engine, IPC protocol, or Neovim Lua plugin:

1. **Do NOT open a public GitHub issue.**
2. Please report the issue privately by opening a [GitHub Security Advisory](https://github.com/igmrrf/distract.nvim/security/advisories/new) or emailing the repository maintainer directly.
3. Provide a detailed summary including steps to reproduce, affected versions, and proof of concept if available.

We will acknowledge receipt within 48 hours and work with you to release a patch promptly.
